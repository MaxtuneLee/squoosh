Squoosh EXIF Preservation Test

📋 Test Instructions

This test verifies that EXIF data is preserved during image compression in Squoosh.

  1. Select a JPEG image that contains EXIF data (camera photos usually have this)
  2. The test will extract EXIF data from the original image
  3. Open the main Squoosh app and compress the same image
  4. Download the compressed image and test it here to verify EXIF preservation
